Short public brief for partners: what it is, live status, on-chain proof, how a buyer pays in ~60 seconds, and what is still open. No chat history required. No operator self-pay.

What it is

  • Pre-payment intelligence for Israeli supplier invoices and company identity. PAY / HOLD / BLOCK with Companies Registry evidence — not Tax Authority login.
  • Paid agent APIs over x402 on Base Mainnet (USDC via Coinbase CDP). No subscription. No API key. Agent/CLI settle, not card checkout.
  • Partner access without crypto: a bearer API key on /v1/pilot/* and /mcp/pilot gives the same four tools with payment waived and usage metered per partner. Invitation-only. Monthly invoice in ₪ or $. Same contracts as the paid routes.
  • Surfaces: REST (/v1/*), MCP (/mcp), discovery (/.well-known/x402).
